## Description

EMIDAF Research Lab is a modular intelligent platform dedicated to data import, inspection, preprocessing, exploratory analysis, statistical analysis, machine learning, explainable artificial intelligence (XAI), decision support, and automated reporting.

The platform is designed for:

- Academic research
- Data science education
- Decision support
- Intelligent data analysis
- Machine learning experimentation
